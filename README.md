# docstring-trap

A tiny shop library. Modules:

- `shop/pricing.py`: discounts
- `shop/dates.py`: business-day maths
- `shop/text.py`: string helpers
- `shop/cache.py`: cache expiry
- `shop/retry.py`: retry helper
- `shop/gateway.py`: fake payment gateway
- `shop/checkout.py`: checkout glue

Run the demo with `python demo.py`.
